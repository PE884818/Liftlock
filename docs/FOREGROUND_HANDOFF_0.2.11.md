# 0.2.11 前景交接与回弹覆盖

追记：实际 SystemUI 已加载 0.2.11 并多次提交 native-exit hidden-frame，新路径没有解决全部问题。用户澄清是桌面壁纸短暂闪成模糊锁屏壁纸，随后文件夹背景采样，并报告半屏按住时时钟持续跳动。0.2.11 验收失败；下方验证中的等待实测是首次安装时的历史状态。

## 真机已观察到的失败

0.2.10 在 boot 140 的 SystemUI、system_server、壁纸及设置进程均加载，用户仍看到文件夹模糊底板变灰，并报告回弹时露出一块锁屏壁纸。因此不再把这次问题解释成 APK 未加载或图标停止绘制。

本轮真实录像按顺序解码、读取实际 PTS，没有用平均帧率或 OpenCV seek 推算时间。在 41.31911 秒、46.80682 秒附近，桌面已显露后锁屏图像短暂回现；后续数帧文件夹底板变灰，图标继续显示。录像含私人内容，不进入源码包，不公开截图。

原生日志显示 `onKeyguardShowingChanged(false)` 内的 `updateKeyguardElementsVisibility()` 仍走 statusBarState=KEYGUARD 分支，直到稍后的状态切换才真正隐藏前景。目标 DEX 源码也显示前一分支可通过 Folme 写回景深 alpha=1。旧版在逻辑 showing=false 回调**之前**恢复前景 alpha、裁切及内容位移，形成了重新绘制锁屏图像的窗口。

结合时序与画面，本轮优先修正这个 UI 恢复缺口；未宣称单独证明了厂商文件夹 PassBlur 的全部内部取样过程。0.2.10 的框架显隐修复及离屏通过不能证明真实文件夹已经修好。

## 实现

- 已经通过模块收起并提交 p=0 的手势，保持闭合帧所有权。逻辑 showing=false 不再立即归还壁纸角色；原生状态回调继续执行。
- 原生显示状态进入非锁屏、景深前景实际不可见后，恢复 View 属性并通过 ViewRoot 的同帧事务提交闭合镜像。该提交回执完成，才结束框架场景与释放镜像。
- 在逻辑隐藏与实际隐藏之间的 pre-draw 中重新应用闭合裁切和透明度，防止原生 alpha=1 更新闪出前景。退出阶段原生元素更新使用原生参数，不再借用拖动阶段的展开比例。
- 重锁、AOD、认证界面、遮挡、停用、异常和原有退出超时仍撤销所有权；没有修改认证标记。
- 回弹结束要同时满足原生高度和**已经呈现的完整覆盖帧**，弹性超出量须归零。取消了“原生进度只要大于零就可结束”的判定，并堵住直接 `finish()` 绕过绘制回执的路径。
- 裁切和模糊使用的高度覆盖实际内容底边，包括呈现追赶期间的弹性超出量及原生位移偏移。该修正保留原始运动高度、速度、位移和透明度公式，露出的返回区域不加入全屏模糊。

原生指纹或其他认证主动结束、尚未经过模块 p=0 提交的流程继续按既有原生分支交接。本轮不能把该分支也宣布为已通过实测。

## 更新与兼容

版本为 0.2.11-stage1 / code 23。系统框架、壁纸适配器与 SceneProtocol 源码和 0.2.10 一致。新 UI 明确接受 0.2.10 框架回执，管理器显示每个进程实际加载版本。框架 0.2.9 及更旧版本仍不兼容；SystemUI 必须加载 0.2.11。

这次在已经加载 0.2.10 框架的手机上只需要管理器重载 SystemUI，无需重启手机或重载壁纸。控制中心、底部优先区域及其预览、HMC 封面处理保持原有实现。

## 验证边界

- release 与 lint 通过。
- JVM 123 项通过，包括 showing=false 尚未原生隐藏、部分呈现不能提前回弹收尾、弹性超出、取消及认证资格分支。
- SDK34 模拟器管理器与角色软件像素 92 项通过：覆盖包含弹性/原生偏移，露出区域仍清晰，模拟厂商 alpha 写回不会闪回前景，实际隐藏后恢复属性不出现旧像素。这里没有澎湃文件夹材质。
- 目标 DEX、字段和模块元数据 306 项通过。新增状态字段和显隐入口均存在；静态检查不是 Hook 实际回调证明。
- myron SDK37 的生产 NativeBlurSheet 探针通过坐标、crop、端点和释放；该探针没有注册窗口，位置回调为手动提供，不证明 RenderThread 或实际模糊像素。
- 安装与手机 base.apk 哈希一致。新版 SystemUI 回执、文件夹灰块、实际回弹缺口、AOD、认证与手感需在重载后的真人操作中检查。没有注入物理屏幕输入、自动重启或回退。

本轮录屏仅定位画面时序，没有形成刷新率或帧性能结论。
