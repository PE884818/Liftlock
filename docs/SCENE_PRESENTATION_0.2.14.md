# 0.2.14 返回首帧与锁屏源退场

本版从 0.2.13 继续修复快划露出未绘制窗口、交接时撤层和旧锁屏源参与桌面采样。真实视觉效果尚未确认。

## 准备与交接

场景使用 PREPARING、REVEALABLE、HANDOFF、NATIVE_OWNED、ENDED 五阶段。会话、窗口身份、Surface 代次、绘制序号及状态序号共同限定回执；历史 isDrawn、RESUME、壁纸 swap 和超时合成的 finishDrawing 不能独立报告应用就绪。

通过目标 WindowState.applyWithNextDraw 请求新绘制。真实绘制事务登记完成回调，工作线程验证 latch 和有效的呈现 fence；接口失败或缺少有效 fence 时保持覆盖。绘制证明失效后重新准备，旧窗口回执不能打开新窗口。

内容仍直接跟随手势与弹簧。独立服务端完整锁屏保护层位于稳定 DisplayArea 中，在返回窗口危险事务中同步保护；原生 Shade 隐藏不能连带撤掉这层。就绪后直接采用当前手势进度。保护层采用实时锁屏镜像，没有加入静态桌面截图。

交接后保留资源，直到当前返回帧已呈现、原生目标及祖先可见、SystemUI 前景隐藏帧提交。资源恢复和保护层撤销放在同一事务，提交后才确认清理。没有 1.5 秒强制撤层或 1.8 秒自动回弹；1.8 秒参数仅为准备期间的对端存活租约，原生已开始交接时续租。准备超过五秒且尚未交出原生控制权时恢复锁屏；原生已解锁不会因计时器重新锁定。

## 壁纸来源

镜像替换与手势取消采用不同恢复路径。分离的实时锁屏生产者维持有效，直到镜像完成交接；只退役锁屏专属源。HOME/LOCK 共享源和同一源角色变化仍由原生管理。捕获 copyFrom 重建的锁屏专属源，在事务提交时拦截退役源的迟到 SHOW。重复 keyguard=true 不重置保护；真正的新锁屏、熄屏、AOD 或明确取消才结束该锁屏周期。

## 验证边界

release、lint、JVM、管理器检查、模拟器自建图层合成和目标 DEX 签名检查通过。SDK37 手机探针只创建自己的离屏容器，验证实际生产助手的事务提交与完成回调，无像素读取、截图、录屏、原生窗口变更或触摸注入。离屏容器没有缓冲帧，因此返回 latched=false、presentFenceSignalled=false，明确没有将其宣布为返回画面就绪。这不能证明真实应用首次呈现、AOD、文件夹采样或手感已通过。

0.2.14/code26 已安装并核对手机 APK 哈希。安装后只读回执显示四进程仍运行 0.2.13；需用户重启一次更新 system_server。新版真实回调、视觉效果和性能尚待确认。
